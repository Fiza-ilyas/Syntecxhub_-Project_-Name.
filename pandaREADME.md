# Pandas CSV Reader & Basic Analysis

A project that uses Pandas to read, analyze, filter and save tabular data.

## What This Project Covers

1. Reading data: loading a CSV file into a DataFrame and inspecting it with head(), tail(), dtypes, shape and info()
2. Summary statistics: mean, median, min, max, count, describe(), groupby() and value_counts()
3. Filtering and selecting: selecting columns, filtering rows with conditions, and slicing with loc and iloc
4. Saving results: exporting filtered data to CSV and Excel files

## Files

- task2.py: main Python script
- students.csv: sample dataset
- top_students.csv and top_students.xlsx: students with marks above 80
- lahore_students.csv: filtered data for Lahore students
- students_report.xlsx: Excel file with 3 sheets

## How to Run

1. Install the libraries: pip install pandas openpyxl
2. Run the script: python task2.py

## Tools Used

- Python 3
- Pandas
- openpyxl
